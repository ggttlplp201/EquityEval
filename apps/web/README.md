# Web workspace

The X1 Sector Explorer provides a graph-first development interface using a
checked, explicitly fictional snapshot. `/sectors` reports production data
prerequisites; `/development/sectors` opens the demonstration. This bounded UI
exception does not implement the S6 API or finish S8/F1 company pages.

From the repository root:

```sh
npm run dev --workspace @equity/web
npm run build --workspace @equity/web
npm run start --workspace @equity/web
```

The interface supports sector and industry bars, dated history, company
histograms, growth-versus-P/E scatter, same-method market references, coverage,
source drawers and the exact frozen company snapshots used in each result.
Missing and nonmeaningful rows remain visible. Below-gate values are outlined;
they are not ranked or placed in the scatter. Breadth is an equal-company
measure, with method switching disabled. Its scatter explicitly uses sector
totals for both axes.

The fictional fixture is generated by the shared Python fundamentals and sector
calculations. No financial ratios, coverage gates, histogram membership or
percentiles are calculated in the browser. The presentation exporter only
formats values and constructs chart geometry; it rejects orphan source details.
Regenerate the complete artifact from the repository root:

```sh
.venv/bin/python scripts/project_python.py scripts/build_sector_fixture.py
.venv/bin/python scripts/project_python.py scripts/export_sector_explorer.py \
  var/sector-explorer-raw.json apps/web/src/features/sectors/fixture.json.gz
```

The gzip artifact is deterministic and keeps complete provenance. The server
expands it for the development page. All date, metric and method variants are
loaded together, so the uncompressed development payload is large; a reviewed
production API will request individual immutable snapshots instead. The internal
TypeScript view model is not a proposed public API contract.

Validation uses `npm run typecheck --workspace @equity/web`, the root lint and
Python presentation tests, `next build`, and browser checks of desktop/mobile,
linked controls, source drilldown, missing states and hydration. The release
milestone records what was actually verified.
