# Frontend

Read root AGENTS.md and docs/spec.txt. The browser renders values supplied by
the API. Arithmetic is limited to display formatting; valuation and ratios are
never computed here. Use the reviewed generated API types after S6.
Every displayed financial number needs provenance and staleness information.
Keep missing values visible as gaps with quality flags. Keep historical modes
separate and assumption changes versioned. S0 creates no pages, layouts or UI.
