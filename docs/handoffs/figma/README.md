## Prompt to use with a designer or Figma assistant

> Read EquityEval_Figma_Design_Handover.md and the feature preservation checklist
> before designing. Redesign equityEval as a graph-led research workbench. Keep
> existing interactions and all planned feature destinations, with explicit
> implemented/planned/deferred status. Map checklist IDs to frames and states.
> Preserve aggregate versus median calculations, coverage and exclusions, exact
> source drilldowns, missing-data states, immutable runs, 3/5/10-year fundamentals,
> full watchlist reruns, continuous stock-specific and macro monitoring, all three
> alert channels and terminology Help. Use fictional labelled examples while
> real-source integration is incomplete. Improve the visual design; do not invent
> financial results, scores, source permissions or working background services.
> Start with the four linked Sector Explorer graphs, then design company
> Fundamentals, Watchlist, News/monitoring health and Help. Retain other research
> features on separate future pages. Return a feature-to-frame mapping and list
> anything not yet represented.

The Figma MCP provides editing tools; it does not independently inherit repository
context or activate live data. The local documents are the complete handover.
